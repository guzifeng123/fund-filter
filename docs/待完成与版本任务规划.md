# 当前状态与版本任务规划

文档版本：v2.7
更新日期：2026-08-13
用途：合并历史完成记录，保留当前状态、已完成能力、待完成事项和发布验收入口。

## 1. 当前状态

项目已从早期 sample demo 进入“本地可运行、功能闭环基本完成、真实生产数据与真实账号体系待接入”的阶段。

已完成的主干能力：

- 前端：Next.js App Router、项目自定义组件、全局 AppShell，以及 dashboard、基金、风险测评、组合、回测、AI、投教与设置等页面入口；审计发现的静态占位和交互缺口已重新列入 P1/P2，不再用“页面存在”等同“功能完成”。
- 后端：FastAPI 路由、统一 API envelope、Pydantic schema、SQLAlchemy ORM、repository/service 分层、Alembic 迁移。
- 数据库：PostgreSQL + pgvector，已包含基金、净值、指标、风险测评、组合、持仓、回测、任务运行、AI thread/message、RAG document/chunk 等核心表。
- 数据源：`sample_local`、`csv_local`、`public_http_json` adapter 已存在；同步任务、数据状态、任务记录和数据新鲜度判断已落地。
- AI：LLM Gateway、mock/真实 provider 边界、SSE、对话持久化、RAG、输入意图 guardrail 与真实 provider 输出后置 guardrail 已落地。
- 质量与运维：后端测试、Ruff、前端 lint/test/build、OpenAPI 导出与 drift 检查、API smoke、Docker Compose 验收脚本、备份/恢复/清理脚本、artifact 汇总与 JSON 报告合同校验已建立。

当前仍未完成或仅为本地降级实现的边界：

- 真实公开基金数据字段映射、缓存、限速和分批同步仍待完善。
- 盈米 MCP 尚未接入。
- LLM Gateway 默认仍可使用 mock provider；真实 OpenAI-compatible provider 已具备超时、重试、输出合规回退、数据库最小化事件、最近窗口指标、阈值状态与保留清理 dry-run/apply。生产前仍需接入外部告警投递、事件清理自动调度和规模化分区/归档策略。
- RAG 检索在 PostgreSQL 环境已切到 pgvector cosine 近邻候选召回，SQLite 测试环境保留应用层计算降级。
- 用户身份仍以 `local-user` 为主，账号体系与多用户隔离未接入。
- CI 级 Playwright E2E 已覆盖 mocked 主路径、异常数据状态及真实 API 的基金/组合/回测/AI 四个合规表面，并生成机器可校验视觉 JSON；脚本化 Playwright/Edge 检查保留为本地补充。

## 4. 推荐执行顺序

1. 先跑 `check-all.ps1` 和 OpenAPI drift，确认代码与合同一致。
2. 再跑数据库迁移、seed、API smoke，确认数据链路可用。
3. 然后跑 Docker Compose 验收，确认真实启动路径可用。
4. 最后跑移动端/主路径 Playwright 脚本并收集 artifacts。

常用命令集中在 README，API 合同看 `docs/API接口说明.md`，数据结构看 `docs/数据字典.md`，合规边界看 `docs/合规边界.md`。

## 5. 暂不纳入 v1.0

- 自动下单、交易执行、调仓指令和收益预测。
- 复杂多账户权限系统。
- 付费订阅、支付、券商账户绑定。
- 全量机构级投顾合规流程。
