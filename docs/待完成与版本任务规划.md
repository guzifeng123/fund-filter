## 1. 当前状态

当前项目已经具备可运行的前后端骨架，并完成了第一轮数据地基改造：

- 前端：Next.js App Router 页面骨架、项目自定义组件、API client、基金页/组合页/回测页/AI 页等主要入口已存在。
- 后端：FastAPI 路由、Pydantic schema、SQLAlchemy ORM、repository 层、Alembic 迁移、幂等 sample seed 命令已存在。
- 数据库：已规划并实现 `funds`、`fund_navs`、`fund_metrics`、`risk_assessments`、`portfolios`、`portfolio_positions`、`backtest_runs`、`job_runs` 等核心表。
- 合规：已有统一 API envelope、免责声明、风险等级匹配基础规则。
- 测试：已有后端业务/API 基础测试，前端 lint/build 可执行。

当前仍处于本地 sample 数据版本，尚未接入公开数据源、盈米 MCP、真实回测引擎和真实 AI/RAG 能力。

## 4. 推荐执行顺序

1. 先完成 v0.1 收尾，确保数据库初始化和 seed 在真实 PostgreSQL 下稳定。
2. 再完成 v0.2，让 API 合同、错误结构和数据状态稳定，减少前后端返工。
3. 进入 v0.3，优先打通基金筛选和比较，这是产品主路径。
4. 完成 v0.4，让风险测评和组合管理成为持久化闭环。
5. 完成 v0.5，把回测从演示数据升级为真实计算。
6. 完成 v0.6，再接外部数据源，避免真实数据直接进入未稳定的数据模型。
7. 完成 v0.7，最后叠加 AI/RAG，确保回答有稳定数据和合规边界。
8. 完成 v0.8 和 v1.0，做质量、文档、部署和发布收口。
