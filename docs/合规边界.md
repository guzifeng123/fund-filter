# 合规边界

文档版本：v1.0  
日期：2026-07-09  
用途：集中说明基金分析、组合、回测和 AI 输出的合规边界，避免页面和服务层出现分散、冲突的文案。

## 1. 核心原则

- 本应用仅用于基金数据整理、风险匹配、历史回测和投教学习。
- 所有分析结果必须展示数据来源、数据日期或更新时间、免责声明。
- 基金筛选和比较必须尊重用户风险测评结果。
- 回测只能解释历史区间表现，不得暗示未来收益。
- AI 输出必须附带限制说明，不能替代持牌机构的适当性意见。

## 2. 统一免责声明

前后端当前维护位置：

- 后端：`apps/api/app/core/compliance.py`
- 前端：`apps/web/src/lib/compliance/constants.ts`

通用免责声明：

```text
本工具基于历史数据，仅供分析学习，不构成投资建议。历史表现不预示未来收益。
```

AI 免责声明：

```text
AI 输出仅供分析学习，不构成投资建议；无法替代持牌机构的适当性意见。
```

维护规则：

- 业务页面不得手写重复免责声明，应引用统一常量或 API `meta.disclaimer`。
- 修改免责声明时必须同步前后端常量，并检查 API contract 示例。
- 涉及基金、组合、回测、AI 的新增页面必须显式展示免责声明。

## 3. 风险等级匹配

用户风险承受等级与可匹配基金风险等级：

| 用户等级 | 可匹配基金 |
| --- | --- |
| C1 | R1 |
| C2 | R1-R2 |
| C3 | R1-R3 |
| C4 | R1-R4 |
| C5 | R1-R5 |

执行规则：

- 筛选推荐结果不得包含超出用户风险承受能力的基金。
- 超配基金允许在搜索、详情、比较中浏览，但必须展示明显风险提示。
- 比较表中超配基金必须高亮，不得弱化风险不匹配信息。
- 当前默认风险画像仍可能为 C3；接入真实用户上下文后必须使用最新风险测评结果。

## 4. 禁止输出

任何页面、API、AI 回复和任务结果不得输出：

- 未来净值、未来收益率或确定性收益承诺。
- 短期买卖点、择时信号、套利策略。
- 自动下单、真实交易或券商操作指令。
- “必须买入”“立即卖出”“保证赚钱”等强交易指令。
- 绕过风险等级匹配的推荐。

## 5. 推荐表达

涉及组合和再平衡时，使用非指令性表达：

- “可考虑用于恢复目标比例。”
- “当前偏离超过阈值，建议进一步查看风险暴露。”
- “该结果用于历史学习，不代表未来表现。”

避免以下表达：

- “必须买入/卖出。”
- “应立即调仓。”
- “未来会获得收益。”

## 6. 回测边界

回测页面和 API 结果必须满足：

- 展示历史表现免责声明。
- 明确展示起止日期、标的、金额、频率和数据来源。
- 净值缺失时返回数据不足提示，不得补出看似精确的结果。
- 不得把历史年化收益、最大回撤、波动率包装成未来收益预测。

## 7. AI 输出模板

AI 对基金、组合和回测的分析应包含：

```text
结论摘要
数据依据
风险点
适合进一步查看的指标
数据日期
免责声明
```

无法回答时必须说明原因，例如数据不足、超出能力范围或问题涉及交易指令。
