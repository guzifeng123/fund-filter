# 数据字典

文档版本：v1.0  
日期：2026-07-09  
适用范围：当前 PostgreSQL schema 与本地测试 SQLite schema。字段以 `apps/api/app/db/models.py` 和 Alembic 迁移为准。

## 1. 通用约定

- 时间字段默认使用带时区时间，后端以 UTC 写入。
- JSON 字段在 PostgreSQL 使用 JSONB，在 SQLite 测试环境降级为 JSON。
- 当前个人版默认 `user_id` 为 `local-user`，后续接入账号体系后应从鉴权上下文注入。
- 当前 sample 净值日期 `trade_date` 仍为年份字符串；接入真实数据源后应迁移为 ISO 日期。

## 2. 基金基础表 `funds`

用途：保存基金基础资料、费用、风险等级、数据来源和 AI 摘要。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | string | 基金代码，主键。 |
| `name` | string | 基金名称，支持搜索索引。 |
| `fund_type` | string | 基金类型，例如 `mixed`、`bond`、`stock`。 |
| `risk_level` | string | 基金风险等级，取值 R1-R5。 |
| `manager_name` | string | 基金经理名称。 |
| `inception_date` | date | 成立日期。 |
| `fund_size_billion` | float | 基金规模，单位：亿元。 |
| `management_fee` | float | 管理费率，单位：%。 |
| `custody_fee` | float | 托管费率，单位：%。 |
| `source` | string | 数据来源，例如 `sample_local`。 |
| `data_updated_at` | datetime | 基金资料更新时间，用于前端新鲜度展示。 |
| `ai_summary` | text | AI 摘要或占位说明。 |
| `raw_data` | json | 原始数据源 payload 快照。 |
| `created_at` | datetime | 创建时间。 |
| `updated_at` | datetime | 更新时间。 |

关联：一只基金有多条 `fund_navs`，最多一条 `fund_metrics`。

## 3. 基金净值表 `fund_navs`

用途：保存基金历史净值点，供净值曲线、回测和指标计算使用。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 主键。 |
| `fund_code` | string | 关联 `funds.code`。 |
| `trade_date` | string | 交易日；当前 sample 为年份字符串。 |
| `nav` | float | 单位净值。 |
| `accumulated_nav` | float | 累计净值。 |
| `raw_data` | json | 原始净值 payload 快照。 |

约束：`fund_code + trade_date` 唯一；基金删除时级联删除净值。

## 4. 基金指标表 `fund_metrics`

用途：保存筛选、比较、详情页和 AI 分析使用的核心历史指标。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `fund_code` | string | 关联 `funds.code`，主键。 |
| `annualized_return_3y` | float | 近 3 年年化收益率，单位：%。 |
| `annualized_return_5y` | float | 近 5 年年化收益率，单位：%。 |
| `max_drawdown` | float | 最大回撤，单位：%。 |
| `sharpe_ratio` | float | 夏普比率。 |
| `category_rank_percentile` | float | 同类排名分位，数值越小排名越靠前。 |
| `manager_years` | integer | 基金经理从业或管理年限。 |
| `raw_data` | json | 指标原始 payload 或计算快照。 |
| `updated_at` | datetime | 指标更新时间。 |

## 5. 风险测评表 `risk_assessments`

用途：保存用户风险测评结果。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 主键。 |
| `user_id` | string | 用户标识，当前默认 `local-user`。 |
| `risk_profile` | string | 用户风险承受等级，取值 C1-C5。 |
| `answers` | json | 风险测评题目和分数。 |
| `assessed_at` | datetime | 测评时间。 |

有效期规则：服务层按 12 个月有效期和到期前提醒计算，不在当前表中冗余保存 `effective_to`。

## 6. 组合表 `portfolios`

用途：保存用户组合、模板选择和目标股债比例。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 组合 ID，主键。 |
| `user_id` | string | 用户标识，当前默认 `local-user`。 |
| `name` | string | 组合名称。 |
| `template_key` | string | 模板 key，例如 `conservative`、`balanced`、`aggressive`。 |
| `stock_ratio` | integer | 目标股票/偏股基金比例，单位：%。 |
| `bond_ratio` | integer | 目标债券/货币基金比例，单位：%。 |
| `config` | json | 模板、阈值或扩展配置。 |
| `created_at` | datetime | 创建时间。 |
| `updated_at` | datetime | 更新时间。 |

## 7. 组合持仓表 `portfolio_positions`

用途：保存组合内基金权重。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 主键。 |
| `portfolio_id` | string | 关联 `portfolios.id`。 |
| `fund_code` | string | 关联 `funds.code`。 |
| `weight_percent` | float | 持仓权重，单位：%。 |
| `metadata` | json | 持仓扩展信息，ORM 字段名为 `metadata_`。 |

约束：`portfolio_id + fund_code` 唯一；基金被持仓引用时限制删除。

## 8. 回测表 `backtest_runs`

用途：保存回测请求和结果快照，确保结果可追溯。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 回测 ID，主键。 |
| `user_id` | string | 用户标识，当前默认 `local-user`。 |
| `strategy_type` | string | 策略类型，例如 `weekly_dca`、`monthly_dca`、`rebalance`。 |
| `request_payload` | json | 回测输入参数快照。 |
| `result_snapshot` | json | 回测结果曲线、指标和数据提示。 |
| `annualized_return` | float | 年化收益率，单位：%。 |
| `max_drawdown` | float | 最大回撤，单位：%。 |
| `volatility` | float | 波动率，单位：%。 |
| `created_at` | datetime | 创建时间。 |

## 9. 数据任务表 `job_runs`

用途：记录 seed、同步、指标计算等任务的运行状态。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 主键。 |
| `name` | string | 任务名，例如 `sync_fund_navs`。 |
| `status` | string | 任务状态，当前应用层使用 `success`、`failed` 等枚举。 |
| `started_at` | datetime | 开始时间。 |
| `finished_at` | datetime/null | 结束时间。 |
| `details` | json | 任务摘要、计数、错误详情。 |

后续优化：如有多语言写库，应增加数据库 CHECK 约束或 PostgreSQL enum。

## 10. AI 对话表 `ai_threads`

用途：保存 AI 对话线程。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 线程 ID，主键。 |
| `user_id` | string | 用户标识，当前默认 `local-user`。 |
| `title` | string | 对话标题。 |
| `created_at` | datetime | 创建时间。 |
| `updated_at` | datetime | 更新时间。 |

## 11. AI 消息表 `ai_messages`

用途：保存 AI 对话中的用户消息和助手消息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 主键。 |
| `thread_id` | string | 关联 `ai_threads.id`。 |
| `role` | string | 消息角色，例如 `user`、`assistant`。 |
| `content` | text | 消息正文。 |
| `payload` | json | 结构化输出、引用、上下文和 guardrail 信息。 |
| `created_at` | datetime | 创建时间。 |
