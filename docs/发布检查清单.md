# 发布检查清单

文档版本：v1.0  
日期：2026-07-09  
用途：发布前固定执行顺序，确保构建、迁移、seed、页面 smoke test 和合规检查都有明确记录。

## 1. 发布前准备

- [ ] 执行环境自检：`.\scripts\check-env.ps1`。
- [ ] 有 Docker 的环境执行初始化验收：`.\scripts\check-env.ps1 -StartPostgres -RunMigrations -SeedSampleData`。
- [ ] 确认 `.env` 来自 `.env.example`，且 `DATABASE_URL`、`NEXT_PUBLIC_API_BASE`、数据源和 LLM 配置符合当前环境。
- [ ] 确认工作区没有误提交的运行产物：`.next`、`.ruff_cache`、`.pytest_cache`、`__pycache__`、`*.egg-info`、`*-dev.log`。
- [ ] 确认 `packages/contracts/openapi.json` 已在后端路由变更后重新导出。

## 2. 数据库与数据

- [ ] 启动数据库：`docker compose up -d postgres`。
- [ ] 执行迁移：`.\scripts\db-migrate.ps1`。
- [ ] 连续执行两次 seed：`python -m app.jobs.seed_sample_data`。
- [ ] 确认 seed 不重复插入基金、净值、指标。
- [ ] 确认 `job_runs` 记录 seed 或同步任务的成功/失败状态。

## 3. 后端质量

- [ ] 运行后端测试：`python -m pytest apps/api/app/tests`。
- [ ] 运行 Ruff：`python -m ruff check apps/api/app`。
- [ ] 运行合规文案检查：`.\scripts\check-compliance-text.ps1`。
- [ ] 启动 API：`npm.cmd run dev:api`。
- [ ] 执行 API smoke：`.\scripts\smoke-api.ps1 -SeedIfEmpty -RequireFresh -JsonReportPath ".\output\smoke\api-smoke.json"`。
- [ ] 确认 `/api/data/status` 在数据为空、过期或同步失败时返回可理解状态。

## 4. 前端质量

- [ ] 运行 lint：`npm.cmd run lint:web`。
- [ ] 运行前端测试：`npm.cmd run test:web`。
- [ ] 运行构建：`npm.cmd run build:web`。
- [ ] 或执行整体验证脚本：`.\scripts\check-all.ps1 -CheckOpenApiDrift`。
- [ ] 启动 Web：`npm.cmd run dev:web`。
- [ ] 桌面端 smoke：dashboard、funds、compare、portfolio、backtest、assistant、settings。
- [ ] 移动端 smoke：基金筛选、基金详情、比较页、组合页、回测页不发生文本溢出或主要操作遮挡。

## 5. 合规与体验

- [ ] 基金、组合、回测和 AI 输出均显示数据来源、数据日期和免责声明。
- [ ] 超出用户风险承受能力的基金有明显提示，且不进入推荐结果。
- [ ] 回测页面展示“历史表现不预示未来收益”。
- [ ] AI 输出包含结论、数据依据、风险点、数据日期和免责声明。
- [ ] 页面覆盖 loading、empty、error、stale 中与当前功能相关的状态。

## 6. Docker Compose 验收

- [ ] 执行完整编排验收：`.\scripts\verify-docker-compose.ps1`。
- [ ] 执行：`docker compose up --build`。
- [ ] Web 可以访问 `http://localhost:3000`。
- [ ] API 可以访问 `http://localhost:8000/health`。
- [ ] Web 能成功读取 API 数据。
- [ ] 关闭服务后重新启动，数据库数据仍保留。

## 7. 发布记录

- [ ] 写入本版本变更摘要。
- [ ] 记录测试命令和结果。
- [ ] 记录未完成事项和已知风险。
- [ ] 如 API contract 冻结，标注 contract 文件版本和导出时间。
